Aula 1 · Primeiro arquivo

🥠 Aplicativo Biscoito da Sorte

Nesta aula, vamos desenvolver somente a funcionalidade do Biscoito da Sorte presente no primeiro arquivo. As telas de Cálculo e Sobre não fazem parte desta atividade.

Conceitos

Componentes, estado com useState, arrays, funções e eventos.

Interface

Imagem/ícone do biscoito, frase da sorte e botão para abrir.

Ambiente

Expo Snack, arquivo principal App.js.

Desenvolvimento passo a passo

1

Criar o projeto no Snack

Acesse snack.expo.dev e crie um projeto em branco. O código será escrito no arquivo App.js. Para esta aula não é necessário instalar bibliotecas extras.

2

Importar React e os componentes

Importe o React, o hook useState e os componentes que serão utilizados na interface.

import React, { useState } from 'react';
import {
  View,
  Text,
  TouchableOpacity,
  StyleSheet
} from 'react-native';
3

Criar o componente e os estados

O estado permite atualizar a frase e a imagem quando o usuário toca no botão. Para facilitar o primeiro teste no Snack, use um emoji no lugar da imagem local do material.

export default function App() {
  const [textoFrase, setTextoFrase] = useState('Frase aqui');
  const [aberto, setAberto] = useState(false);

  // restante do código virá aqui
}
4

Montar o array de frases

O array armazena as mensagens disponíveis para o sorteio.

const frases = [
  'Sorte é estar preparado quando a oportunidade aparece.',
  'Um passo de cada vez leva longe.',
  'Acredite no seu potencial!',
  'O sucesso começa com um pensamento positivo.',
  'Grandes coisas levam tempo.'
];
5

Criar a função que abre o biscoito

Math.random() gera um valor aleatório. Math.floor() transforma o resultado em um índice inteiro válido para acessar uma frase do array.

function quebrarBiscoito() {
  const num = Math.floor(Math.random() * frases.length);
  setTextoFrase('"' + frases[num] + '"');
  setAberto(true);
}
6

Construir a interface

Organize os elementos em uma View. O TouchableOpacity cria o botão e o evento onPress chama a função.

return (
  <View style={estilos.container}>
    <Text style={estilos.biscoito}>
      {aberto ? '🥠' : '🥠'}
    </Text>

    <Text style={estilos.textoFrase}>
      {textoFrase}
    </Text>

    <TouchableOpacity
      style={estilos.botao}
      onPress={quebrarBiscoito}
    >
      <Text style={estilos.btnTexto}>Abrir Biscoito</Text>
    </TouchableOpacity>
  </View>
);
7

Aplicar os estilos e testar

Use StyleSheet.create() para centralizar os elementos, definir tamanho de fonte, cores, margens e aparência do botão. Teste várias vezes e observe se a frase muda.

const estilos = StyleSheet.create({
  container: {
    flex: 1, alignItems: 'center',
    justifyContent: 'center',
    backgroundColor: '#fff', padding: 20
  },
  biscoito: { fontSize: 110 },
  textoFrase: {
    fontSize: 18, color: '#dd7b22',
    margin: 30, fontStyle: 'italic',
    textAlign: 'center'
  },
  botao: {
    width: 200, height: 45,
    backgroundColor: '#dd7b22',
    borderRadius: 25, alignItems: 'center',
    justifyContent: 'center'
  },
  btnTexto: { color: '#fff', fontWeight: 'bold', fontSize: 16 }
});
Atenção: no arquivo original, as imagens são carregadas com require('../assets/...'). Se você quiser usar essas imagens no Snack, envie os arquivos de imagem para a pasta assets e ajuste os caminhos. O emoji acima é uma alternativa para executar o exercício sem esses arquivos.

Aula 2 · Arquivo novo

📍 Aplicativo de consulta de CEP

Nesta aula, vamos criar um aplicativo que recebe um CEP, consulta a API ViaCEP e apresenta os dados do endereço. O projeto trabalha com estados, validação, função assíncrona, requisição HTTP, tratamento de erros e indicador de carregamento.

Conceitos

useState, TextInput, validação, async/await e fetch.

API utilizada

ViaCEP: consulta de endereço por CEP.

Ambiente

Expo Snack, arquivo principal App.js.

Abrir Expo Snack ↗

Desenvolvimento passo a passo

1

Criar o projeto

Acesse snack.expo.dev e crie um projeto em branco. O código será desenvolvido no arquivo App.js. O arquivo de referência também apresenta a criação de um projeto Expo local, mas nesta aula vamos executar pelo Snack.

2

Importar os componentes

Importe useState do React e os componentes do React Native. O ActivityIndicator será exibido enquanto a consulta estiver em andamento.

import { useState } from 'react';
import {
  View, Text, TextInput, Button,
  StyleSheet, ActivityIndicator
} from 'react-native';
3

Criar os estados

Precisamos armazenar o CEP digitado, os dados retornados pela API e a informação de carregamento.

const [cep, setCep] = useState('');
const [dados, setDados] = useState(null);
const [loading, setLoading] = useState(false);

cep guarda o texto digitado; dados começa como null e receberá o objeto da API; loading controla o indicador de carregamento.

4

Criar a função buscarCep()

A função verifica se foram digitados oito caracteres. Se estiver correto, ativa o carregamento, limpa o resultado anterior e faz a consulta com fetch.

async function buscarCep() {
  if (!cep || cep.length !== 8) {
    alert('Digite um CEP válido (somente números)');
    return;
  }

  setLoading(true);
  setDados(null);

  try {
    const resposta = await fetch(
      `https://viacep.com.br/ws/${cep}/json/`
    );
    const json = await resposta.json();

    if (json.erro) {
      alert('CEP não encontrado!');
    } else {
      setDados(json);
    }
  } catch (error) {
    alert('Erro ao consultar o CEP');
  }

  setLoading(false);
}
5

Entender a consulta à API

A URL recebe o CEP digitado e retorna os dados em formato JSON. O comando await aguarda a resposta da internet e resposta.json() converte o conteúdo para um objeto JavaScript.

https://viacep.com.br/ws/01001000/json/

Exemplo de CEP para teste: 01001000.

6

Montar o campo de entrada e o botão

O TextInput recebe o CEP. A propriedade maxLength limita a digitação a oito caracteres e onChangeText atualiza o estado.

<TextInput
  style={styles.input}
  placeholder="Digite o CEP (somente números)"
  keyboardType="numeric"
  maxLength={8}
  value={cep}
  onChangeText={setCep}
/>

<Button title="Buscar CEP" onPress={buscarCep} />
7

Exibir carregamento e resultado

Renderize o indicador enquanto loading for verdadeiro. Quando dados possuir conteúdo, mostre as propriedades retornadas pela API.

{loading && (
  <ActivityIndicator size="large" style={{ marginTop: 20 }} />
)}

{dados && (
  <View style={styles.result}>
    <Text>CEP: {dados.cep}</Text>
    <Text>Logradouro: {dados.logradouro}</Text>
    <Text>Bairro: {dados.bairro}</Text>
    <Text>Cidade: {dados.localidade}</Text>
    <Text>Estado: {dados.uf}</Text>
    <Text>DDD: {dados.ddd}</Text>
  </View>
)}
8

Estilizar e testar

Utilize StyleSheet.create() para definir o espaçamento, o campo de entrada e o cartão de resultado. Teste um CEP válido, um CEP inexistente e um valor com menos de oito dígitos.

const styles = StyleSheet.create({
  container: {
    flex: 1, padding: 20, paddingTop: 60,
    backgroundColor: '#fff'
  },
  titulo: {
    fontSize: 22, fontWeight: 'bold',
    marginBottom: 20, textAlign: 'center'
  },
  input: {
    borderWidth: 1, padding: 12,
    borderRadius: 5, marginBottom: 15
  },
  result: {
    marginTop: 25, padding: 20,
    backgroundColor: '#f3f3f3', borderRadius: 8
  },
  label: { fontSize: 16, marginBottom: 5 }
});
Importante: a API ViaCEP é acessada pela internet. Se a consulta falhar, verifique a conexão e confira se o CEP foi digitado corretamente. O código-base do arquivo valida a quantidade de caracteres e trata CEP não encontrado e erro na requisição.
Atividade 2 · Individual ou dupla

Personalize o aplicativo de consulta de CEP

Com base no aplicativo desenvolvido na aula, implemente as melhorias abaixo mantendo a consulta à API ViaCEP funcionando.

  1. Adicione uma máscara visual ao CEP, exibindo-o no formato 00000-000 (a consulta à API deve continuar enviando somente números).
  2. Inclua um botão Limpar que apague o CEP digitado e os dados exibidos.
  3. Mostre uma mensagem na própria tela quando o CEP não for encontrado, em vez de utilizar apenas alert().
  4. Organize os dados retornados em um cartão visual (um VIEW formatado), destacando cidade e estado.
  5. Teste com um CEP válido, um CEP inexistente e um CEP incompleto.
