# Aulas React Native no Expo Snack

Site estático feito com HTML, CSS e Bootstrap 5.3.3.

## Conteúdo
- Aula 1: Biscoito da Sorte (somente a funcionalidade do primeiro arquivo).
- Aula 2: Consulta de CEP com a API ViaCEP, baseada no arquivo `6. CEP no frontend.txt`.
- Uma atividade prática por aula.

## Publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie `index.html`, `vercel.json` e este README para a raiz do repositório.
3. Na Vercel, escolha **Add New → Project** e importe o repositório.
4. Como é um site estático, não precisa de build command nem de framework preset.
5. Clique em **Deploy**.
